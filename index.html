Henry System Pattern Reference Manual

Pattern Symbols & Designations

  • Whorls (W, C, D, X): Plain Whorl (W), Central Pocket Loop (C), Double Loop (D), Accidental Whorl (X). Evaluated for Primary numerical value + Sub-Secondary / Major Tracing.
  • Loops (U, R): Ulnar Loop (U), Radial Loop (R). Evaluated by Ridge Counting.
  • Arches (A, T): Plain Arch (A), Tented Arch (T). Evaluated as small-letter extensions in Secondary classification.

Sub-Secondary Ridge Count Thresholds

For Loop patterns on Index, Middle, and Ring fingers:

INDEX
1-9: I (Inner)
10+: O (Outer)
MIDDLE
1-10: I (Inner)
11+: O (Outer)
RING
1-13: I (Inner)
14+: O (Outer)

Major Division Evaluation (Thumbs)

Left Thumb Loop count determines scale used for Right Thumb:

  • Left Thumb Standard Scale: S (1-11), M (12-16), L (17+)
  • Right Thumb Scale:
      if Left Thumb is S, M, Arch, or Whorl → Standard (S: 1-11, M: 12-16, L: 17+)
      if Left Thumb is L (17+) → Extended (S: 1-16, M: 17-21, L: 22+)
